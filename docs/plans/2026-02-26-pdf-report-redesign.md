# PDF Report Redesign — Colorful Financial Report

**Date:** 2026-02-26
**Status:** Approved

---

## Overview

Redesign the existing PDFKit-based financial report (`pdf-report.service.ts`) from a bland, text-heavy layout into a colorful, modern report with dashboard-style metric cards, horizontal bar charts, visual progress indicators, infographic elements, and styled tables. No new dependencies — uses PDFKit's native drawing APIs.

**Target:** 3-4 page balanced layout (not too dense, not too sparse).
**Style:** Modern fintech dashboard meets infographic — bold color cards, visual charts, clean typography.

## Page Layout

### Page 1: Header + Financial Summary + AI Insights

**Full-width header banner (60pt tall):**
- Teal background (`headerBg`)
- "SPENDOZA" in white, bold, 24pt, centered
- Report title ("Personal — Monthly Report") in white, 12pt
- Month name in lighter white, 10pt
- Rounded bottom corners (decorative)

**4 metric cards in 2x2 grid:**
Each card is a rounded rectangle (approx 235pt wide x 70pt tall) with:
- Colored left border strip (4pt wide)
- Light tinted background matching the metric type
- Small label text (9pt, muted color): "TOTAL INCOME"
- Large value (18pt, bold, metric color): "$8,450"
- Small trend indicator (8pt): "↑ 3.2% vs last month" in green or "↓ 5.1%" in red

| Card | Border Color | Background | Value Color |
|---|---|---|---|
| Total Income | `income` | `incomeBg` | `income` |
| Total Expenses | `expense` | `expenseBg` | `expense` |
| Net | `net` | `netBg` | `net` |
| Savings Rate | `savings` | `savingsBg` | `savings` |

**AI Insights callout box:**
- Full-width rounded rectangle with `netBg` background and `net` left border (3pt)
- "AI INSIGHTS" label in blue, bold, 10pt
- Insight text in 9pt dark, with bullet points
- Subtle padding (12pt)

### Page 2: Expense Breakdown + Recurring Bills

**Expense Breakdown — Horizontal Bar Chart:**
- Section header: bold 13pt with teal underline bar (full section width)
- Each category row (22pt tall):
  - Category name left-aligned (10pt, dark)
  - Horizontal colored bar, width proportional to percentage (max = page width * 0.5)
  - Bar colors cycle through: `#10b981`, `#3b82f6`, `#8b5cf6`, `#f59e0b`, `#ef4444`, `#06b6d4`, `#ec4899`, `#64748b`
  - Amount + percentage right-aligned (10pt)
  - Rounded bar ends (3pt radius)
- Total row at bottom with bold styling and top divider

**Recurring Bills — Styled Table:**
- Header row: `headerBg` background, white text, 9pt bold
- Data rows: alternating white / `rowAlt` background
- Amount column in bold
- Thin divider lines between rows

### Page 3: Income, Subscriptions, Goals

**Income Sources — Styled Table:**
Same styling pattern as Recurring Bills table.

**Subscriptions — Compact Table + Summary Callout:**
- Same styled table
- Below table: a small callout box (`amberBg` background, `amber` border) showing:
  - "Total: $X/mo — X.X% of expenses"

**Goal Progress — Visual Bars:**
Each goal gets a block (~45pt tall):
- Goal name in bold 10pt + type/category in muted 8pt
- Thick rounded progress bar (12pt tall, 3pt border radius)
  - Background: `#e2e8f0`
  - Fill: green (on track), red (over budget), amber (behind)
- Percentage label to right of bar (bold, colored)
- Status pill: small rounded rectangle with text ("On Track" green, "Over Budget" red, "Behind" amber)
- Detail line: "Spent $X of $Y — Target: Mar 2026"

### Page 4 (conditional): Savings Opportunities + Member Contributions

**Savings Opportunities:**
Each recommendation in a card-style box:
- `amberBg` background, `amber` left border
- Category name bold, amount and percentage
- Suggestion text below in muted

**Member Contributions (household only):**
Styled table with income column in green, expenses column in red.

### Footer (every page)
- Thin teal line across page width
- "Generated by Spendoza on [date]" centered, 8pt muted
- Page number right-aligned

## Implementation Approach

Rewrite `packages/api/src/services/pdf-report.service.ts` entirely. The `PdfReportInput` interface stays the same — only the drawing code changes. No API route changes needed, no frontend changes needed.

### New Drawing Helpers Needed

| Helper | Purpose |
|---|---|
| `drawHeaderBanner` | Full-width teal banner with title/subtitle |
| `drawMetricCards` | 2x2 grid of colored stat cards |
| `drawInsightsBox` | Blue callout box for AI insights |
| `drawBarChart` | Horizontal bar chart for expense categories |
| `drawStyledTable` | Table with colored header, alternating rows |
| `drawGoalProgress` | Thick progress bar with status pill |
| `drawCalloutBox` | Generic colored callout (for subscriptions summary, savings recs) |
| `drawPageFooter` | Footer line + text + page number |
| `drawSectionTitle` | Bold title with colored underline bar |

### What Changes
- **File:** `packages/api/src/services/pdf-report.service.ts` — full rewrite of drawing logic
- **No other files change** — the function signature (`buildReportPdf(input)`) and return type (`Promise<Buffer>`) remain identical
